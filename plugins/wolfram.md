## 它是什麼？

Wolfram plugin 讓 ChatGPT 呼叫 Wolfram 的計算與知識服務。你用中文描述問題，ChatGPT 整理成查詢或 Wolfram Language 運算，取得工具結果後再解釋。

Wolfram|Alpha 以整理過的知識與計算方法產生答案；查新聞、比較網站文章等工作仍適合交給網路搜尋工具。Wolfram Language 則適合明確指定公式、資料、計算流程與圖形。

本文以目前連接的 plugin 為準。舊文章中的 ChatGPT plugin、Wolfram GPT 與不同 MCP 部署方式，安裝步驟、工具與額度可能不同。

## 可以直接複製的使用範例

以下是給 ChatGPT 的自然語言指令。除文末標明的兩個計算外，其餘為使用情境範例，未在本次逐一執行驗證。

### 1. 解方程式並驗算

> 使用 Wolfram 解 x² − 5x + 6 = 0，列出所有實數解，再把解代回原式驗算。用繁體中文簡短解釋。

適合：核對作業或自行推導的結果。這題應得到 x = 2、3。

### 2. 微積分與圖形

> 使用 Wolfram 計算 f(x) = x³ − 3x 的導數，找出 −2 ≤ x ≤ 2 內的局部極值，並畫出函數曲線、標示極值位置。分開說明局部極值與區間最大最小值。

適合：把公式、計算結果與圖形一起理解。

### 3. 單位換算

> 使用 Wolfram 將時速 72 公里換成公尺／秒，顯示單位換算過程。

適合：減少單位混用造成的錯誤。這題應得到 20 m/s。

### 4. 物理模型與假設

> 使用 Wolfram 計算理想彈簧振子的週期：質量 0.5 kg、彈簧常數 200 N/m。列出公式、代入值、單位與結果，並說明忽略阻尼的假設。

適合：檢查公式與量綱，以及理解模型成立的條件。

### 5. 統計分析

> 使用 Wolfram 分析這組資料：12、15、15、18、20。計算平均數、中位數、樣本標準差，畫出資料分布。說明樣本標準差使用 n−1 的分母，並提醒這五筆資料能支持哪些結論。

適合：小型資料摘要、核對統計計算。推論結果仍受抽樣方式與資料量限制。

### 6. 迭代模型與非線性動力學

> 使用 Wolfram 分析 logistic map：x_(n+1) = r x_n(1−x_n)。設定 x₀ = 0.2，分別取 r = 2.8、3.2、3.9，各迭代 300 次，丟棄前 200 次，畫出剩下的時間序列。列出參數與數值精度設定；請把有限次模擬的觀察和數學證明分開。

適合：探索收斂、週期與混沌行為。有限次迭代、近似重複或一張圖，都不足以單獨證明長期動態。

### 7. 查科學知識與資料來源

> 使用 Wolfram 查詢火星的質量、平均半徑與表面重力，整理成含單位的表格。附上來源及可取得的資料時間；工具沒有提供時間時請明說。

適合：查詢可計算的科學知識。資料定義、更新時間與缺漏仍需確認。

## 如何讓結果容易檢查？

可以在指令後補上：

> 請先說明你如何理解輸入，列出公式、假設、單位與參數。區分精確值和數值近似，附上實際使用的查詢或程式碼。工具失敗時請明說。

計算工具能協助檢查運算；題目解讀、模型選擇、輸入資料與 AI 的文字解釋仍可能出錯。關鍵結果可代回原式、檢查單位，或用另一種方法交叉驗證。

## 使用限制與費用提醒

- **自然語言可能被誤解**：檢查工具的輸入解讀，尤其是括號、變數範圍、日期與單位。有歧義時拆成單一問題。
- **符號答案可能附帶條件**：實數／複數、參數範圍與邊界條件會影響解。
- **數值精度與計算時間有限**：混沌、病態問題或大型掃描需特別注意；本次 evaluator 工具預設時間限制為 60 秒，實際支援範圍依服務為準。
- **本次 evaluator 為無狀態**：不同呼叫之間不能依賴前次定義的變數；一次計算需包含必要定義與資料。
- **知識資料有更新週期**：即使服務能提供部分近期資料，也應核對每筆資料的時間與來源。
- **不保證每題都有完整教學步驟**：可要求 ChatGPT 解釋，但需分清工具回傳內容與 AI 補充推導。
- **費用與額度需另確認**：已連接 plugin 不代表包含 Wolfram|Alpha Pro、完整 Mathematica 授權或無限運算；以 plugin 連線介面及對應服務條款為準。
